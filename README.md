The goal of this project is to classify 40 emails into one of the 4 following categories:
1. `booking_inquiry`, meaning customer asking about availability, prices, or making a new booking
2. `confirmation`, where customer is confirming or accepting a new reservation
3. `booking_follow_up`, Customer is asking about an existing booking
4. `unrelated`, Message is not about booking or managing a reservation.


**Important distinction** A message saying "Can you confirm availability?" is a `booking_inquiry`, not a `confirmation`
